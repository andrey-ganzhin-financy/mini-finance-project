# mini-finance-project
Цель: Демонстрация навыков работы с формулами и логикой в Excel.
Что реализовано в модели:
Расчет налогов (13% от оклада) с использованием функции ОКРУГЛВВЕРХ.
Логическая проверка премий через функцию ЕСЛИ.
Блок статистического анализа: рассчитаны СУММ, СРЗНАЧ, МЕДИАНА. Выявлен выброс в данных (разница между медианой и средним).
Оформление данных в денежный формат и построение сводной таблицы.
